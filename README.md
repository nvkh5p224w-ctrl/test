# Functions Assignment

Six Python programs covering functions, parameters, return values, loops, and basic calculations.

## Programs
1. `problem1_extended_price.py` - quantity and price, 10% discount over $10,000, running total.
2. `problem2_batting_average.py` - batting average and player count.
3. `more_functions1_sales_forecast.py` - next-month sales forecast by month.
4. `more_functions2_auto_price.py` - vehicle discount, 7% tax, MSRP and sales totals.
5. `advanced1_discount.py` - returns discount amount and discounted price.
6. `advanced2_student_scores.py` - returns total exam points and average.

## Notes
- Problems 1 and 2 use a sentinel value to stop.
- Problems in the More Functions section use Yes/No to continue or stop.
- Run each program from a terminal with `python filename.py`.
- Screenshots of sample runs are in the `screenshots` folder.
